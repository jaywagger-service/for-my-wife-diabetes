### 5-B. welcome 레이아웃 문제 원인 추정

위치: `app/welcome/page.tsx:35`

```tsx
<div className="min-h-dvh bg-bg flex flex-col px-6 py-10 justify-between">
```

문제:

- 최상위 컨테이너가 viewport 전체 폭을 그대로 사용합니다.
- 내부 콘텐츠 wrapper에 `max-w-[480px] mx-auto` 또는 유사 폭 제한이 없습니다.
- 입력 필드와 버튼은 `w-full`이라 데스크탑에서 화면 전체 폭으로 확장됩니다.
- `justify-between`은 세로축 분산용이지만, 폭 제한이 없는 상태에서 상단 텍스트 블록과 하단 입력 블록이 모두 와이드 컨테이너에 배치되어 PC/태블릿에서 레이아웃이 비정상적으로 보일 수 있습니다.

검토 결과:

- `app/welcome/page.tsx`에 `grid grid-cols-2` 없음
- `app/welcome/page.tsx`에 텍스트를 좌우 컬럼으로 나누는 명시적 grid 없음
- 주된 원인은 **모바일 전용 화면에 있어야 할 중앙 폭 제한 누락**으로 판단됩니다.

수정 권장:

- welcome도 다른 페이지와 동일한 패턴으로 감싸기

```tsx
<div className="min-h-dvh bg-bg">
  <ToastProvider />
  <div className="max-w-[480px] mx-auto min-h-dvh flex flex-col px-6 py-10 justify-between">
    ...
  </div>
</div>
```

또는 기존 최상위 div에 직접:

```tsx
className="min-h-dvh bg-bg flex flex-col px-6 py-10 justify-between max-w-[480px] mx-auto"
```

단, 배경색이 전체 viewport에 깔리도록 첫 번째 wrapper 방식이 더 일관됩니다.
